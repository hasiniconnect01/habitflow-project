# Habit Flow

A daily habit tracker with cloud-backed storage.

## Features

- Add habits with a name and description
- Check off habits for today — one check-in per day per habit
- Streaks calculated automatically from check-in history
- Seven-day history dots and weekly rhythm bar chart
- Today's progress ring with percentage and encouraging message
- Export habit data as JSON
- Data persists in Supabase (cloud database), not just the browser

## Tech

- React + Vite
- Supabase for data storage (habits + daily check-ins)
- lucide-react for icons

## Run

```bash
npm install
npm run dev
```
